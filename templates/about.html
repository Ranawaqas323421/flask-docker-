ABOUT PROJECT

Flask Docker Practice

This project is intentionally small so you can focus on the DevOps workflow instead of complicated application code.

Technologies

  • Python 3
  • Flask
  • pip
  • requirements.txt
  • Docker
  • Linux
  • AWS EC2

Practice Goal

Install dependencies, run Flask locally, create a Dockerfile, build an image, run a container, map ports, inspect logs, publish the image and deploy the application on EC2.
